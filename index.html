📘 지표 정의

DAU — 해당일 앱 로그인한 순(unique) 유저 수. 1일 단위(00:00~23:59) 집계.
신규 회원 — 해당일 가입 완료된 회원 수. 신규 회원 정의는 "가입한 달 이력" 기준. (데이터 적재 시작: 2025-05-30)
신규 첫 로그인 — 가입 후 30일 이내 앱에 처음 로그인한 유저 수.
신규 기기 등록 — player_id 기준 신규 발급 기기 수. 강의 수강 시 기기 등록이 필수라 실질적 강의 시작 지표.
위젯 이용자 — 위젯(퀵/최근/통계) 중 1개 이상 설치=Y인 로그인 유저.
Activation Rate = 신규 첫 로그인 ÷ 신규 회원 · 강의 시작률 = 신규 기기 등록 ÷ 신규 첫 로그인
Widget Adoption = 위젯 이용자 ÷ DAU · DAU 내 신규 비중 = 신규 첫 로그인 ÷ DAU

🔗 Google Sheets 연결

시트를 연결하면 시트의 데이터가 대시보드에 자동 반영됩니다. 팀원 여러 명이 시트에 입력하고, 모두가 이 페이지에서 실시간으로 볼 수 있어요.

로컬 편집 모드 (연결된 시트 없음)
📖 Google Sheets 연결 방법 (처음이라면 클릭)
  1. dashboard_template.xlsx 파일을 Google Drive에 업로드 → 우클릭 → 연결 앱 → Google Sheets로 열기
  2. 열린 시트의 daily_metrics 탭에서 데이터를 입력·확인 (헤더 이름은 절대 변경하지 말 것)
  3. 상단 메뉴 파일 → 공유 → 웹에 게시
  4. 왼쪽 드롭다운에서 daily_metrics 시트 선택, 오른쪽 드롭다운에서 쉼표로 구분된 값(.csv) 선택
  5. 게시 버튼 클릭 → 발급된 URL 복사 (...pub?output=csv 형태)
  6. 위 입력창에 URL 붙여넣기 → 🔗 연결 버튼 클릭
  7. 완료! 이후 시트에 데이터를 추가하면, 이 페이지에서 🔄 새로고침 버튼으로 즉시 반영할 수 있습니다.

💡 팀에 공유하려면 이 index.html을 GitHub Pages 등에 올리고 URL을 공유하세요. 시트 데이터는 URL을 열 때마다 자동으로 최신 값이 로드됩니다.
